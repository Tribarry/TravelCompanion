# Destination planning audit

- Destination tabs include a Proposed Schedule.
- Modes: 1 DAY, 2 DAYS, 3 DAYS and BUILD MY OWN.
- Suggestions use personal ratings first, then canonical priority.
- Keep, Swap, Move and Remove actions persist independently from Saved/Done/rating state.
- Go Next now resolves the next unfinished destination across chronological journey order.
- Don't Miss is a global utility containing fixed commitments plus unfinished S+/S experiences, excluding Done, Skipped and personal Pass ratings.
